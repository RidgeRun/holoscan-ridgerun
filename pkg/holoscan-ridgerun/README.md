# holoscan-ridgerun package

This directory defines the Debian package for the complete
`holoscan-ridgerun` module. The package declaration includes the registered
camera, display, Interprocess, pipeline, V4L2, and YOLO11 applications together
with their reusable C++ operators.

## Usage

From the module root:

```bash
./holoscan_ridgerun package holoscan-ridgerun --pkg-generator DEB
```

The command configures the package project, builds the registered applications
and operators, and invokes CPack's Debian generator. It does not install the
resulting package on the host.

To verify command resolution and inspect the generated CMake/CPack commands
without building, run:

```bash
./holoscan_ridgerun package holoscan-ridgerun \
  --pkg-generator DEB \
  --local \
  --dryrun
```

To build against the SDK and dependencies installed on the host, omit
`--dryrun`:

```bash
./holoscan_ridgerun package holoscan-ridgerun \
  --pkg-generator DEB \
  --local
```

After the command completes, locate and inspect the artifact without installing
it:

```bash
find build -type f -name 'holoscan-ridgerun*.deb' -print
dpkg-deb --info build/<path-to-package>/holoscan-ridgerun*.deb
dpkg-deb --contents build/<path-to-package>/holoscan-ridgerun*.deb
```

Replace `<path-to-package>` with the path printed by `find`. If `lintian` is
installed, the package can also be checked with:

```bash
lintian build/<path-to-package>/holoscan-ridgerun*.deb
```

The package project is registered by [`pkg/CMakeLists.txt`](../CMakeLists.txt)
and the Debian metadata is generated by
[`pkg/holoscan-ridgerun/CMakeLists.txt`](CMakeLists.txt).

## Holoscan SDK (HSDK) dependency

The package selects the SDK runtime dependency by architecture:

- x86_64: `holoscan-cuda-13 (>= 5.0.0)`
- aarch64: `holoscan (>= 5.0.0)`

The selected SDK package must match the SDK and CUDA environment used to build
and test the module. Additional runtime dependencies, such as display or
camera libraries, belong in the `DEPENDS` value in `CMakeLists.txt` when they
are required by the deployment image.
